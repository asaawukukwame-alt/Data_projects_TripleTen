# Movie Review Sentiment Classification

## Project Description

This project focused on building a natural language processing model to classify movie reviews as positive or negative.

The goal was to use text preprocessing and machine learning to automatically detect sentiment from written reviews.

## Objective

The objective was to train and evaluate classification models that can predict review sentiment from text data.

## Tools and Technologies

- Python
- pandas
- NumPy
- scikit-learn
- NLTK / text preprocessing
- TF-IDF / vectorization
- Classification models
- F1 score
- Jupyter Notebook
- Natural Language Processing

## Methods

The project included the following steps:

1. Loaded and reviewed the movie review dataset.
2. Cleaned and normalized text data.
3. Prepared features using text vectorization.
4. Split the data into training and testing sets.
5. Trained and compared classification models.
6. Evaluated model performance using F1 score.
7. Interpreted the model results from a business and product perspective.

## Results

The project demonstrated how machine learning can be used to classify customer sentiment from text reviews.

The model was evaluated using F1 score, which is useful when balancing precision and recall in classification problems.

## Business Value

Sentiment classification can help companies automatically analyze customer feedback, product reviews, support messages, and social media comments.

This type of model can support faster decision-making by identifying positive and negative customer experiences at scale.
