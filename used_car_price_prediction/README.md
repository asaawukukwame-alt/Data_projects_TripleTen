\# Used Car Price Prediction



\## Project Description



This project focused on building regression models to predict used car prices based on vehicle characteristics.



The goal was to compare model performance, training speed, prediction speed, and business usefulness for a used car marketplace.



\## Objective



The objective was to build a model that can estimate used car prices accurately while also considering how practical the model would be for real business use.



\## Tools and Technologies



\* Python

\* pandas

\* NumPy

\* scikit-learn

\* LightGBM

\* CatBoost

\* Regression modeling

\* RMSE

\* Feature engineering

\* Categorical encoding

\* Jupyter Notebook



\## Methods



The project included the following steps:



1\. Loaded and reviewed the used car dataset.

2\. Cleaned missing values and handled data quality issues.

3\. Prepared numerical and categorical features.

4\. Trained and compared multiple regression models.

5\. Evaluated models using RMSE.

6\. Compared training speed and prediction speed.

7\. Selected the model that provided the best balance of accuracy and efficiency.



\## Results



The project demonstrated how regression models can be used to estimate used car prices from vehicle data.



The model comparison considered both prediction quality and practical business performance.



\## Business Value



Used car price prediction can help marketplaces, dealerships, and buyers estimate fair vehicle prices.



A useful model can support pricing decisions, reduce manual appraisal time, and improve customer trust in listed prices.
