# Used Car Price Prediction — Rusty Bargain

## Project Description

This project focused on building a regression model to estimate used car prices for a vehicle marketplace. The goal was to help users quickly estimate car values based on vehicle features.

## Objective

The objective was to compare different regression models and select a model that balanced prediction quality, training time, and prediction speed.

## Tools and Technologies

- Python
- pandas
- NumPy
- scikit-learn
- LightGBM
- Random Forest
- Decision Tree
- Linear Regression
- OneHotEncoder
- Pipelines
- RMSE
- Jupyter Notebook

## Methods

The project included the following steps:

1. Loaded and reviewed the used car dataset.
2. Cleaned missing and unusual values.
3. Prepared categorical and numerical features.
4. Built preprocessing pipelines for encoding and imputation.
5. Trained Linear Regression, Decision Tree, Random Forest, and LightGBM models.
6. Compared models using RMSE.
7. Measured training time and prediction speed.
8. Selected a model based on both quality and practical performance.

## Results

The project showed how different machine learning models perform on a used car price prediction task. Model selection considered both prediction accuracy and speed, which is important for real-world deployment.

## Business Value

A used car marketplace could use this model to estimate fair vehicle prices, improve user experience, support sellers with pricing guidance, and help buyers evaluate listings.
